How Google ADK Exports Telemetry in Production

Standard setup for Google Cloud Trace & Cloud Monitoring

The Google Native ADK automatically generates semantic OpenTelemetry traces and metrics internally when wrapping agents and tools. In production, you simply configure the OTel SDK to export to the GCP Operations suite:

from opentelemetry import metrics, trace
from opentelemetry.sdk.metrics import MeterProvider
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.exporter.otlp.proto.grpc.metric_exporter import OTLPMetricExporter
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPTraceExporter
from opentelemetry.sdk.metrics.export import PeriodicExportingMetricReader
from opentelemetry.sdk.trace.export import BatchSpanProcessor

# Initialize Trace and Metric Providers
trace.set_tracer_provider(TracerProvider())
metrics.set_meter_provider(MeterProvider(
    metric_readers=[PeriodicExportingMetricReader(OTLPMetricExporter(endpoint="gcp-otel-collector:4317"))]
))
trace.get_tracer_provider().add_span_processor(BatchSpanProcessor(OTLPTraceExporter(endpoint="gcp-otel-collector:4317")))

# The Google ADK will now automatically push agent and tool spans/histograms to Cloud Logging, Trace and Monitoring!
