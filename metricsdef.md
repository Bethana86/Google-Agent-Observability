# OpenTelemetry Metrics Definition Guide (`metricsdef.md`)

This document provides a concise definition, purpose, unit of measure, and metric type for all **58 active OpenTelemetry (OTel) metrics** instrumented under the `gcp.vertex.agent` standard for the **Agent Platform Performance Monitoring System**.

---

## 7. FinOps & Tokenomics (8 Metrics)
Combines financial accounting, model API invocation spend, tokenomics efficiency, tool payload bandwidth costs, and network data egress expenses.

| Metric Name | OTel Signal ID | Type | Unit | Short Description |
|---|---|---|---|---|
| **Model API Invocation Cost** | `gen_ai.agent.cost` | Histogram | USD ($) | Cumulative API financial spend for LLM model invocations. |
| **Cost per Conversational Turn** | `gen_ai.finops.cost_per_turn` | Histogram | USD ($) | Estimated financial cost for completing a single conversation turn. |
| **Prompt Input Tokenomics** | `gen_ai.agent.token.prompt` | Counter | Tokens | Total input prompt tokens consumed by agents across models. |
| **Completion Output Tokenomics** | `gen_ai.agent.token.completion` | Counter | Tokens | Total output completion tokens generated by agents. |
| **Total Tokenomics Volume** | `gen_ai.agent.token.total` | Counter | Tokens | Aggregate volume of input and output tokens processed. |
| **Active Session Token Footprint** | `gen_ai.workflow.tokens.active` | Histogram | Tokens | Active session context window token size footprint. |
| **Tool Payload Bandwidth Expense** | `gen_ai.tool.payload.size` | Histogram | Bytes | Network payload throughput volume from external tool API calls. |
| **Cache Savings Cost Efficiency** | `gen_ai.finops.cache_savings_ratio` | Histogram | % | Percentage of tool executions served from cache saving API re-runs. |

## 1. Agent Performance (20 Metrics)
Focuses on individual agent execution efficiency, token economy, latency overhead, decision quality, memory interaction, and resilience.

| Metric Name | OTel Signal ID | Type | Unit | Short Description |
|---|---|---|---|---|
| **Agent Invocation Latency** | `gen_ai.agent.invocation.duration` | Histogram | ms | Time taken by an agent to execute an end-to-end task turn. |
| **Request Payload Size** | `gen_ai.agent.request.size` | Histogram | Bytes | Total bytes sent in the incoming prompt request to the agent. |
| **Response Payload Size** | `gen_ai.agent.response.size` | Histogram | Bytes | Total bytes generated in the agent's output response. |
| **Workflow Execution Steps** | `gen_ai.agent.workflow.steps` | Histogram | Count | Number of discrete execution steps completed during a task turn. |
| **Total Invocations** | `gen_ai.agent.calls.count` | Counter | Count | Total number of times an agent was invoked. |
| **Agent Execution Errors** | `gen_ai.agent.errors.count` | Counter | Count | Total unhandled runtime errors encountered during agent execution. |
| **Prompt Token Usage** | `gen_ai.agent.token.prompt` | Counter | Tokens | Total input/prompt tokens consumed by the agent. |
| **Completion Token Usage** | `gen_ai.agent.token.completion` | Counter | Tokens | Total output/completion tokens generated by the agent. |
| **Total Token Usage** | `gen_ai.agent.token.total` | Counter | Tokens | Aggregate count of all input and output tokens consumed. |
| **Estimated Cost** | `gen_ai.agent.cost` | Histogram | USD ($) | Estimated financial cost of token usage for the agent turn. |
| **Retry Attempts** | `gen_ai.agent.retry.count` | Counter | Count | Number of internal retry attempts executed due to transient faults. |
| **Agent Latency Overhead** | `gen_ai.agent.latency.overhead` | Histogram | ms | Framework and orchestration overhead excluding pure LLM inference time. |
| **Handoff Count** | `gen_ai.agent.handoff.count` | Counter | Count | Number of times the agent transferred control to another agent. |
| **Reasoning Drift Score** | `gen_ai.agent.reasoning.drift` | Histogram | Score | Divergence metric tracking agent adherence to original system prompt intent. |
| **RCA Search Depth** | `gen_ai.agent.root_cause.depth` | Histogram | Nodes | Depth of diagnostic tree searched during root cause analysis. |
| **RCA Confidence Score** | `gen_ai.agent.root_cause.confidence` | Histogram | % | Statistical confidence score of the agent's diagnostic output. |
| **Memory Read Operations** | `gen_ai.agent.memory.reads` | Counter | Count | Number of read queries made to persistent session/vector memory. |
| **Memory Write Operations** | `gen_ai.agent.memory.writes` | Counter | Count | Number of state/context update writes made to persistent memory. |
| **User Feedback Score** | `gen_ai.agent.feedback.count` | Counter | Count | Explicit positive/negative feedback signals logged for agent responses. |
| **Fallback Triggers** | `gen_ai.agent.fallback.triggered` | Counter | Count | Count of safe default fallback handlers executed upon task failure. |

## 2. Tool Diagnostics (8 Metrics)
Measures tool invocation speeds, execution success rates, caching efficiency, payload throughput, concurrency, and timeout events.

| Metric Name | OTel Signal ID | Type | Unit | Short Description |
|---|---|---|---|---|
| **Tool Execution Duration** | `gen_ai.tool.execution.duration` | Histogram | ms | Time required for an external function tool or API call to complete. |
| **Tool Calls Count** | `gen_ai.tool.calls.count` | Counter | Count | Total number of tool invocations across all agents. |
| **Tool Failures Count** | `gen_ai.tool.errors.count` | Counter | Count | Total failed or erroring tool execution calls. |
| **Tool Cache Hits** | `gen_ai.tool.cache.hit` | Counter | Count | Tool requests served directly from local/redis cache. |
| **Tool Cache Misses** | `gen_ai.tool.cache.miss` | Counter | Count | Tool requests requiring full external API re-execution. |
| **Tool Payload Size** | `gen_ai.tool.payload.size` | Histogram | Bytes | Combined byte payload size of tool arguments and response output. |
| **Tool Concurrency** | `gen_ai.tool.concurrency` | UpDownCounter | Count | Active concurrent tool executions occurring simultaneously. |
| **Tool Timeout Count** | `gen_ai.tool.timeout.count` | Counter | Count | Tool invocations aborted due to exceeding max deadline time. |

## 3. Session & Workflow (10 Metrics)
Tracks end-to-end multi-agent session lifecycle, working context size, conversational turns, queue delays, and concurrent execution capacity.

| Metric Name | OTel Signal ID | Type | Unit | Short Description |
|---|---|---|---|---|
| **Session Duration** | `gen_ai.workflow.duration` | Histogram | ms | Total elapsed wall-clock time for an entire multi-agent workflow session. |
| **Active Agents Count** | `gen_ai.workflow.active_agents` | UpDownCounter | Count | Number of sub-agents concurrently active in the workflow pipeline. |
| **Session Memory Footprint** | `gen_ai.workflow.memory.usage` | Histogram | Chars | Character size of active working memory state held in session context. |
| **Active Context Tokens** | `gen_ai.workflow.tokens.active` | Histogram | Tokens | Total active context window tokens maintained across session history. |
| **Conversational Turns** | `gen_ai.workflow.turns.count` | Counter | Turns | Total user-agent interaction turns completed in the session. |
| **Workflow Run Successes** | `gen_ai.workflow.success.count` | Counter | Runs | Number of multi-agent sessions successfully fulfilling user intent. |
| **Workflow Run Errors** | `gen_ai.workflow.errors.count` | Counter | Runs | Number of multi-agent sessions terminating in unrecoverable failure. |
| **Workflow Queue Delay** | `gen_ai.workflow.queue.delay` | Histogram | ms | Time spent in dispatch queues waiting for execution resources. |
| **Handoff Chain Depth** | `gen_ai.workflow.handoff.depth` | Histogram | Depth | Maximum length of agent-to-agent delegation chains in a single run. |
| **Concurrency Limit** | `gen_ai.workflow.concurrency.limit` | Histogram | Slots | Maximum configured concurrent agent execution slots available. |

## 6. Policy & Governance (6 Metrics)
Monitors security guardrails, edge network protections via **Google Cloud Armor**, and content safety/data privacy blocks via **Model Armor**.

| Metric Name | OTel Signal ID | Type | Unit | Short Description |
|---|---|---|---|---|
| **Cloud Armor Blocked Requests** | `gen_ai.security.cloud_armor.blocked` | Counter | Count | Incoming network requests blocked by Cloud Armor WAF security rules. |
| **Cloud Armor Violations** | `gen_ai.security.cloud_armor.violations` | Counter | Count | Security policy rate limit or geo-restriction violations detected. |
| **Model Armor Injection Blocks** | `gen_ai.security.model_armor.prompt_injection` | Counter | Counter | Adversarial prompt injection attacks intercepted by Model Armor. |
| **Model Armor Jailbreak Blocks** | `gen_ai.security.model_armor.jailbreak` | Counter | Counter | System prompt override and jailbreak attempts blocked by Model Armor. |
| **Model Armor PII Leak Blocks** | `gen_ai.security.model_armor.pii_leak` | Counter | Counter | Sensitive Personally Identifiable Information (PII) leaks prevented. |
| **Model Armor Safety Triggers** | `gen_ai.security.model_armor.safety_triggers` | Counter | Counter | Harmful, toxic, or unsafe content outputs blocked by safety filters. |
